# Cambios portada y dashboard

## Portada
- El producto principal ya no usa texto ni placeholder fijo si no existe un producto activo marcado desde el dashboard.
- El producto destacado ya no usa texto fijo si no existe un producto activo marcado desde el dashboard.
- Si un producto se desactiva, desaparece automáticamente de la portada aunque esté marcado como principal o destacado.
- La descripción y foto mostradas en Inicio salen desde los datos del producto en Dashboard > Productos.

## Dashboard > Productos
- Se agregó edición de producto existente: SKU, nombre, categoría, unidad, descripción, estado activo, principal y destacado.
- Se mantiene gestión de fotos por URL para cada producto.
- Se agregó aviso para dejar claro que solo los productos activos y marcados aparecen en Inicio.

## Navbar
- Se ajustó la marca de la navbar para no duplicar/superponer el texto FRICAR cuando el logo ya viene desde una URL del dashboard.
- El logo del menú se toma desde Branding/Dashboard y, si la imagen ya contiene el texto FRICAR, no se agrega otro texto al lado.
