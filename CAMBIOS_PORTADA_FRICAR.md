# Cambios portada FRICAR

- Se reemplazó el favicon de React por el isotipo de FRICAR.
- Se actualizaron `favicon.ico`, `favicon.png`, `logo192.png`, `logo512.png` y `apple-touch-icon.png`.
- Se editó la página principal para usar la información del pantallazo: hero, áreas de trabajo, quiénes somos, identidad visual, contacto y ubicación.
- El producto principal y el producto destacado de la página de Inicio ahora se leen desde el dashboard de Productos.
- En el modelo de productos se agregaron los campos `principalHome` y `destacadoHome`.
- En el dashboard de Productos se agregaron controles para marcar o quitar un producto como principal o destacado.
- El backend deja solo un producto principal y solo un producto destacado activo por vez cuando se marca uno nuevo.
