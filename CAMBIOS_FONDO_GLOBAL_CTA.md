# Cambios finales: fondo global y CTA Home

- Se agregó el fondo circular/decorativo al contenedor global `PageShell`, para que se vea en Catálogo, Contacto, Cotizar, Cotizaciones, Requerimientos, Dashboard, Productos, Usuarios, Perfil, Login y Registro.
- Se agregaron orbes y patrón de puntos decorativos reutilizables en todas las páginas internas.
- Se corrigió el contenedor azul del Home tipo CTA “¿Necesitas algo específico?” para que no quede pegado, cortado ni desordenado.
- El CTA ahora usa grid responsive, mejor padding, degradado, sombra y botón proporcionado.
- Se mantuvieron las funcionalidades existentes sin alterar la lógica del proyecto.
