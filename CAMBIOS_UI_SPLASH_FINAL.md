# Cambios UI final + loader inicial

- Se cambió el loader global de peticiones por un splash inicial tipo app, parecido a Instagram/Facebook.
- El splash aparece solo al entrar por primera vez durante la sesión del navegador, con logo FRICAR, barra animada y texto de marca.
- Se reforzó el fondo visual en todas las páginas usando degradados, patrones suaves y tarjetas tipo glass.
- Se mejoró la semántica y jerarquía visual del Home: hero más amplio, mejor composición, fondo más dinámico y bloques más ordenados.
- Se rediseñó Contacto con layout de dos columnas, datos comerciales y formulario más limpio.
- Se rediseñó Productos del dashboard para que las tarjetas no se deformen: preview de imagen, descripción controlada, metadatos, acciones ordenadas y edición más clara.
- Se mantiene intacta la lógica funcional de productos, portada, imágenes, activación/desactivación y flags de producto principal/destacado.
